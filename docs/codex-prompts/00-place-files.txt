현재 저장소 안에 Codex 설정 파일 폴더가 있다.
먼저 `placement-manifest.json`과 `placement-guide.md`를 읽고, 각 파일을 manifest의 target_path에 맞게 저장소 내부에 복사 또는 이동해라.

작업 규칙:
1. 어떤 파일을 어떤 경로로 배치할지 먼저 요약해라.
2. target 경로에 이미 파일이 있으면 바로 덮어쓰지 말고 차이를 먼저 보여줘라.
3. 배치 후에는 실제로 반영된 최종 경로 목록을 정리해라.
4. 이후 작업은 저장소 루트의 `AGENTS.md`와 `docs/user-part-spec.md`를 기준으로 수행해라.
5. prompt 파일들은 `docs/codex-prompts/` 아래에 정리해라.
